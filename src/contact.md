## Reporting a problem

If a file won't convert, these details help me find the cause quickly:

- the page you were on, for example *HEIC to JPG*
- your browser and device, for example *Chrome on Windows 11* or *Safari on iPhone*
- the exact error message, if one appeared
- where the file came from, for example *iPhone 15 camera* or *exported from Excel*

Please don't email files that contain anything private. WrenConvert never needs your files, which is the whole point of it. If a sample would really help and the file is harmless, mention it and we can work out a way.

## Requesting a format

Tell me which format you want to convert from and to, and what you need it for. Requests that come up often get built first.

## Other things

Business enquiries, corrections to anything written on the site, and licensing questions about the open-source code all go to the same address.
